## Format Specifications

### Sprite Sheets
- **Layout**: Horizontal or grid
- **Frame size**: Consistent (e.g., 64x64 per frame)
- **Frames**: 4-8 frames per animation
- **Example**: `fx-slash.png` - 8 frames, 512x64 or 256x256

### Overlays
- **Format**: PNG with transparency
- **Size**: Match screen resolution (1920x1080)
- **Blend mode**: Screen or Additive
