# 📋 Логирование запросов - Краткое руководство

## Что было добавлено

Полная система трассировки запросов от фронтенда к бэкенду и обратно с детальным логированием каждого шага.

## 🎯 Как это работает

### 1. Фронтенд (Браузер)

Каждый запрос API логируется с:
- **Уникальным Trace ID** для отслеживания
- **Детали запроса**: метод, endpoint, headers, body
- **Время отправки**
- **Ответ сервера**: статус, время обработки, данные
- **Ошибки**: детальная информация об ошибках

### 2. Бэкенд (Сервер)

Каждый полученный запрос логируется с:
- **Trace ID** (из фронтенда)
- **Request ID** (внутренний ID)
- **Детали**: метод, путь, клиент, пользователь
- **Путь через систему**: роутер → сервис → ядро
- **Время обработки**
- **Результат**: успех/ошибка

## 🚀 Как использовать

### Для разработчиков

#### Frontend

```typescript
// Логирование автоматическое - просто делайте запросы
const response = await api.post('/sessions', {
    session_name: 'My Game'
});
// Проверьте консоль браузера для деталей
```

#### Backend

```python
from backend.src.logging import get_trace_id, RequestTracer

@router.post("/example")
async def example_endpoint():
    trace_id = get_trace_id()
    
    # Логирование входа
    print(f"🚀 ENTERING: example_endpoint")
    
    # Использование контекстного менеджера
    with RequestTracer("operation", {"data": "value"}):
        # Ваш код
        pass
    
    # Логирование выхода
    print(f"✅ EXITING: example_endpoint")
```

## 🔍 Отладка

1. **Откройте DevTools** (F12) в браузере
2. **Перейдите на вкладку Console**
3. **Сделайте запрос** из фронтенда
4. **Найдите Trace ID** в логах
5. **Проверьте консоль сервера** для того же Trace ID
6. **Проследите путь** запроса через систему

## 🎯 Преимущества

- ✅ **Полная видимость**: Проследите запрос от начала до конца
- ✅ **Easy Debugging**: Найдите проблему по Trace ID
- ✅ **Мониторинг производительности**: Время обработки каждого запроса
- ✅ **Отслеживание ошибок**: Точное место возникновения ошибки
- ✅ **Аудит**: Полный лог всех API взаимодействий

## 📊 Пример потока

```
USER ACTION (клик кнопки)
    ↓
FRONTEND: 📤 REQUEST (Trace: abc123)
    ↓ (HTTP)
BACKEND: 📥 INCOMING (Trace: abc123)
    ↓
BACKEND: 🚀 ENTER: create_session
    ↓
BACKEND: 💾 DATABASE operation
    ↓
BACKEND: ⚙️ ENGINE processing
    ↓
BACKEND: 📤 RESPONSE (Trace: abc123, 245ms)
    ↓ (HTTP)
FRONTEND: 📥 RESPONSE (Trace: abc123, 245ms)
    ↓
UI UPDATE (навигация, успех)
```

## 🔒 Безопасность

- Auth токены замаскированы (`Bearer ***`)
- Чувствительные заголовки исключены из логов
- Trace ID случайные и не угадываемые
