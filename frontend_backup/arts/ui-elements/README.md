# UI Elements

## Required UI Assets

### Logo (256x256, PNG)
- `ui-logo.png` - Main MAGGxDND logo
- `ui-logo-small.png` - Small version (64x64)
- `ui-logo-wordmark.png` - Text only version

### Buttons (200x50, PNG)
- `ui-button-default.png` - Normal state
- `ui-button-hover.png` - Mouse over state
- `ui-button-active.png` - Clicked state
- `ui-button-disabled.png` - Disabled state

### Button Variants
- `ui-button-primary-*` - Primary action (gold/blue)
- `ui-button-secondary-*` - Secondary action (gray)
- `ui-button-danger-*` - Delete/cancel (red)

### Panels (PNG)
- `ui-panel-small.png` - 400x300, info panels
- `ui-panel-medium.png` - 600x400, character sheet
- `ui-panel-large.png` - 800x600, main content
- `ui-panel-modal.png` - Modal dialog background

### Decorative Elements
- `ui-border-corner.png` - 32x32 corner piece
- `ui-border-edge.png` - 32x4 edge tile
- `ui-divider.png` - 800x4 section divider
- `ui-ornament.png` - Decorative flourish

### Icons & Indicators
- `ui-heart.png` - HP indicator (32x32)
- `ui-star.png` - MP/XP indicator (32x32)
- `ui-sword-icon.png` - Attack icon (32x32)
- `ui-shield-icon.png` - Defense icon (32x32)
- `ui-clock-icon.png` - Turn/time icon (32x32)
- `ui-chat-icon.png` - Chat/message icon (32x32)

### Cursors
- `ui-cursor-default.png` - Normal cursor
- `ui-cursor-pointer.png` - Clickable hover
- `ui-cursor-attack.png` - Combat target

---

## Style Guide
- **Colors**: Match game palette
- **Borders**: 2-4px fantasy style
- **Gradients**: Subtle, not overwhelming
- **Shadows**: Soft drop shadows for depth
