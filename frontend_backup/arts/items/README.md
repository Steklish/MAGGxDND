## Style Guide
- **Size**: 64x64 pixels
- **Format**: PNG with transparency
- **Style**: Clear silhouettes, readable at small sizes
- **Colors**: Vibrant but consistent palette
- **Border**: Optional 2px dark border for contrast

## Export Versions
- `icon-name.png` (64x64)
- `icon-name@2x.png` (128x128)
- `icon-name@3x.png` (192x192)
