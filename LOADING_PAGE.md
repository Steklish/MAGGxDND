# 🎲 Loading Page with D20 Dice Animation

## Обзор

Создана страница загрузки с анимацией броска D20 кубика для всех переходов между страницами (кроме создания игры).

## ✨ Особенности

### 1. Анимация D20 Кубика

**Основные элементы:**
- Большой D20 кубик в центре экрана
- Анимация броска (вращение + масштабирование)
- История последних бросков внизу
- Эффекты для критических успехов/провалов

**Анимации:**
- **Бросок**: Кубик вращается 2 секунды
- **Приземление**: Плавная остановка с отскоком
- **Частицы**: Плавающие частицы на фоне

### 2. Система Бросков

**История бросков:**
```
[15] [7] [20] [3] [18]
  ↑    ↑   ↑    ↑   ↑
  |    |   |    |   └─ Последний
  |    |   |    └───── Предпоследний
  |    |   └────────── и т.д.
```

**Критические эффекты:**
- **20 (Critical Success)**: Зеленое свечение, текст "🎉 Критический успех! 🎉"
- **1 (Critical Fail)**: Красное свечение, текст "💀 Критический провал! 💀"
- **15-19**: "✨ Успех! ✨"
- **10-14**: "👍 Неплохо"
- **2-9**: "😅 Неудача"

### 3. Загрузочная Полоса

```
┌────────────────────────────────┐
│ ████████████████████████░░░░░░ │  ← Пульсирующий градиент
└────────────────────────────────┘
```

### 4. Советы по Игре

10 случайных советов для D&D:
- "Совет: Проверяйте характеристики вашего персонажа перед боем."
- "Совет: Взаимодействуйте с NPC для получения ценной информации."
- "Совет: Исследуйте мир внимательно - тайны повсюду!"
- И еще 7 советов...

## 🎨 Визуальные Эффекты

### Фон
- Градиент: Темно-серый → Черный
- Плавающие частицы с оранжевым свечением
- Анимация: частицы появляются и исчезают

### D20 Кубик
```
     ╱╲
    ╱  ╲
   ╱ 20 ╲  ← Светящиеся грани
  ╱      ╲
 ╱________╲
```

### Анимации
1. **diceRoll**: Вращение на 360° с масштабированием
2. **diceLand**: Плавное приземление после броска
3. **float**: Парящие частицы
4. **dotPulse**: Пульсирующие точки загрузки
5. **loadingPulse**: Пульсирующая полоса загрузки
6. **messageFade**: Появление текста

## 🔧 Использование

### В App.tsx

```typescript
// Переход с загрузкой
transitionToPage(() => {
    setShowProfile(true);
}, 'Загрузка профиля...');
```

### Параметры

```typescript
interface LoadingPageProps {
    message?: string;      // Сообщение загрузки
    showDice?: boolean;    // Показывать ли кубик (default: true)
}
```

### Примеры

```tsx
// Стандартная загрузка
<LoadingPage message="Загрузка..." />

// Без кубика
<LoadingPage message="Сохранение..." showDice={false} />

// Кастомное сообщение
<LoadingPage message="Подготовка приключения..." />
```
